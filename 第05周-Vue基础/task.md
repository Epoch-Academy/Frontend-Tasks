# 第 5 周任务：社团广场 v0.1（主线项目第一版）

> **本周起，第 5～8 周共用同一个项目 `campus-clubs`（校园社团招新平台），每周在上一周基础上迭代一个版本：v0.1 → v0.2 → v0.3 → v1.0。第 8 周的结业项目就是这个项目的最终版本。**

## 本周定位

- 版本：**v0.1**；
- 用 Vue 基础把主线项目的「社团广场」这一屏做出来，数据先用本地文件模拟；
- 本周重点是熟悉 Vue 的「数据驱动视图」思路，**不要求拆分组件**（组件化在第 6 周）。

## 项目创建启动

创建命令（下面两种方式任选其一，Vue 3 + Vite；**不要两个都跑**，否则会生成两个同名目录或互相覆盖）：

```bash
# 方式一：官方脚手架（交互式）
npm create vue@latest campus-clubs
# ↓ 会依次问你项目名和 Router / Pinia 等选项：
#   Project name：直接按回车，用默认的 campus-clubs
#   Router / Pinia / ESLint 等选项：本周全部选 No（多按几次回车）

# 方式二：Vite 模板（更轻，本周够用；非交互，一条命令直接生成）
npm create vite@latest campus-clubs -- --template vue
```

创建后进入项目、装依赖、启动：

```bash
cd campus-clubs
npm install
npm run dev        # 看到本地地址（一般 http://localhost:5173）即成功
```

第 6、7 周只会在**这个目录**里改代码和加依赖（例如第 7 周的 `vite.config.js` 代理配置、`.env` 环境变量），**不要重建项目**；**Vue Router 留到第 8 周才装**（第 6、7 周的示例项目都没有它，本周创建项目时也要选 No）。

## 任务目标

使用 Vue 3 + Vite 在主线项目 `campus-clubs` 中完成「社团广场」单页，掌握单文件组件、声明式渲染、常用指令、`ref`、`computed`、`watch`、表单绑定和本地存储的基础用法。

## 指引

重点关注以下内容：

- Vue 单文件组件的基本结构：`<script setup>`、`<template>`、`<style>`；
- `ref` 和模板中的自动解包；
- `v-model` 在搜索框等表单控件中的使用；
- `v-for`、`v-if`、`v-else`、`v-bind`、`v-on` 等常用指令；
- `computed` 用于派生数据（筛选结果、排序、统计）；
- `watch` 用于处理本地存储等副作用；
- 列表渲染时稳定 `key` 的使用；
- 动态 class、空状态和基础交互反馈。

本周先不要急着拆组件，把状态、派生数据和副作用的关系理顺。

## 本轮要求（主线项目增量）

1. 使用 Vue 3 + Vite 创建主线项目 `campus-clubs`。
2. 新建 `src/data/clubs.js`，提供不少于 8 条社团数据，字段**统一固定**为：
   - `id`、`name`（社团名称）、`category`（分类）、`intro`（简介）、`members`（成员数）、`tags`（标签数组）、`hot`（热度）。
   - 这套字段第 6～8 周保持不变，请提前设计好。
3. 页面至少包含：标题区、搜索区、分类筛选区、统计区、社团列表区、空状态。
4. 列表必须使用 `v-for` 渲染，并使用**稳定的 `key`**（用社团 `id`，不要用数组下标）。
5. 搜索框用 `v-model` 绑定关键词；提供分类筛选（「全部」+ 各分类）；提供至少一种排序（例如按热度）。
6. 使用 `computed` 派生：筛选后的列表、当前结果数量、社团总数、已收藏数量。
7. 实现收藏功能：
   - 点击卡片上的收藏按钮，在「收藏 id 数组」中**新增或移除**；
   - 提供「仅看收藏」筛选；
   - 支持清空收藏。
8. 使用动态 `class` 区分「已收藏 / 未收藏」状态。
9. 使用 `watch` + `localStorage` 持久化收藏 id，刷新页面后收藏状态能够恢复。
10. 搜索无结果、收藏为空时要有明确的空状态提示，不能出现空白页面。
11. **响应式 API 与指令要真的用上**（对应学习指南的知识点清单）：
    - 状态里至少各用一次 `ref` 和 `reactive`，并能说明两者读取 / 修改的差别；
    - 至少各用一次 `computed` 和 `watch`，并能说明它们分别解决什么问题；
    - `v-if` 与 `v-show` 至少各用一次，并在代码注释里写一句「这里为什么选它」（例如空状态用 `v-if`、频繁切换的提示用 `v-show`）。

## 完成标准

- `npm install`、`npm run dev` 后项目可以正常运行；
- 搜索、分类筛选、排序、结果统计之间能够正确联动；
- 收藏、取消收藏、「仅看收藏」、清空收藏均正常工作；
- 刷新页面后收藏状态能够恢复；
- 列表 key 稳定，控制台无重复 key 警告；
- 无结果 / 无收藏时显示空状态，不出现白屏；
- 项目不存在阻断使用的控制台错误；
- 代码中能指出 `ref`、`reactive`、`computed`、`watch`、`v-if` 和 `v-show` 的实际使用位置；
- 能现场说明 `ref`、`reactive`、`computed`、`watch`、`v-model`、`v-for key` 和 `localStorage` 的基本作用。
