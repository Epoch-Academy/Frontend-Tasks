# 第 5 周学习指南：Vue 3 基础 —— 社团广场 v0.1

## 〇、本周在主线项目中的位置

从本周到第 8 周，所有任务都在**同一个项目** `campus-clubs`（校园社团招新平台）上迭代，每周只做增量改造：

| 周 | 版本 | 在项目上叠加的能力 |
| --- | --- | --- |
| 05 | v0.1 | 单页 + 本地数据：列表渲染、搜索筛选排序、收藏、本地存储 |
| 06 | v0.2 | 组件化重构：拆组件、Props/Emit、插槽、生命周期、Composable |
| 07 | v0.3 | 对接接口 + 报名：请求封装、请求状态、表单校验、环境变量与代理 |
| 08 | v1.0 | 路由化 SPA：多视图、params/query、嵌套路由、登录守卫、404、懒加载 |

**从第 4 周过来**：上周你手动做「取元素 → 改内容 → 同步别处」，本周换成「只维护状态，让 Vue 更新视图」。本周可以不写 `document.querySelector`、不写 `createElement`——如果你发现自己在 Vue 里手动操作 DOM，基本说明思路还停在上周。

## 一、本周总学习目标

- 能使用 Vite 创建、启动和构建 Vue 3 项目；
- 理解单文件组件与声明式渲染；
- 能使用常见指令完成表单和列表交互；
- 能使用 `ref`/`reactive` 管理响应式状态；
- 能正确区分 `computed` 和 `watch` 的基础使用场景；
- 能用 `localStorage` 保存并恢复用户数据。

## 二、本周学习任务

1. 使用 Vite 创建主线项目 `campus-clubs`，熟悉启动、构建和项目目录；这是第 5～8 周共同的代码库；
2. 练习单文件组件、模板语法和常用 Vue 指令；
3. 使用 `ref`、`reactive` 和 `v-model` 管理搜索条件与列表状态；
4. 使用 `computed` 完成筛选、排序和统计，使用 `watch` 处理收藏的本地保存；
5. 使用动态 class 展示收藏状态，正确设置列表 key 和空状态；
6. 按照 [task.md](./task.md) 完成「社团广场」v0.1；
7. 使用 Vue Devtools 和控制台检查状态、警告及本地数据异常情况。
