# 第 5 周学习指南：Vue 3 基础

> 本周创建主线项目 `campus-clubs`，完成 v0.1“社团广场”。从现在开始只维护状态，由 Vue 根据状态更新页面，不再手动拼 DOM。

## 学完你能做什么

- 使用 Vite 创建、启动和构建 Vue 3 项目；
- 使用 Vue 指令和响应式状态完成列表交互；
- 使用 `computed`、`watch` 和 `localStorage` 处理派生数据与收藏。

## 推荐学习顺序

1. 创建项目，认识 `src`、`main.js`、`App.vue` 和 `package.json`。
2. 学习模板语法，以及 `v-bind`、`v-on`、`v-if`、`v-for`、`v-model`。
3. 使用 `ref` 或 `reactive` 保存搜索、筛选和收藏状态。
4. 使用 `computed` 生成筛选、排序和统计结果。
5. 使用 `watch` 保存收藏，再按照 [task.md](./task.md) 完成 v0.1。

第 5～8 周会持续修改这一个项目，请保留每周已有功能。

## 核心知识

- [ ] Vite 的 `dev`、`build` 和项目入口；
- [ ] 单文件组件与 `<script setup>`；
- [ ] 条件渲染、列表渲染和稳定的 `key`；
- [ ] `ref`、`reactive` 与模板自动解包；
- [ ] `computed` 与 `watch` 的区别；
- [ ] `v-model` 和动态 class；
- [ ] 数据驱动视图。
