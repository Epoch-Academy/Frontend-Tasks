# 第 3 周学习指南：JavaScript 基础

## 一、本周总学习目标

- 能写出合法的 JavaScript 基础语法；
- 能正确使用变量、常量、数据类型和运算符；
- 能用条件语句和循环处理简单逻辑；
- 能用函数封装可复用的计算过程；
- 能独立处理数组和对象的读取、遍历、修改与汇总；
- 能使用浏览器控制台定位语法和运行问题。

## 二、本周学习任务

1. 熟悉 `script` 标签、注释、命名规范和代码缩进；
2. 掌握 `let`、`const`、基本数据类型和类型转换；
3. 理解算术运算、比较运算和逻辑运算的常见写法；
4. 练习 `if`、`switch`、`for`、`while` 和 `for...of` 等基础流程控制；
5. 学会编写函数、传参、返回值和简单的参数校验；
6. 掌握数组和对象的创建、读取、遍历和常见操作；
7. 了解字符串、Math、Date 和 JSON 的基础用法；
8. 练习数据清洗：处理缺字段、类型不对、重复和超出范围的数据，并记录问题；本周要求 5 类问题各至少 1 处（类型不对、`id` 重复、缺字段、方向为空、成绩非法），清洗策略见 [task.md](./task.md) 的表格；
9. 练习按字段分组统计，以及同分同名次的并列排名；**平均分统一保留 1 位小数**（`Math.round(值 * 10) / 10`），录取建议阈值提取成常量；
10. 按照 [task.md](./task.md) 完成“招新成员数据处理器”；
11. 用 `document.querySelector` + `createElement` + `textContent` 把统计摘要渲染到页面上，先体会“用 JS 生成页面元素”（这是下周 DOM 的起点，本周只做最小渲染）；
12. 用控制台逐条核对输出结果，遇到报错先看第一行出错位置再动手改；
13. 整理 `README.md` 并用 Git 提交本周代码。

## 完成自检

- `let` 和 `const` 的使用边界是什么？
- 为什么 `===` 通常比 `==` 更安全？
- `undefined` 和 `null` 有什么区别？
- 函数为什么要尽量只做一件事？
- 为什么排序前最好先复制数组而不是直接修改原数组？
- 对象和数组分别适合表示什么类型的数据？
- `JSON.stringify` 和 `JSON.parse` 的作用分别是什么？
- 清洗数据时，什么情况应该“修复”，什么情况应该“丢弃”？
- 平均分保留 1 位小数，用 `Math.round(值 * 10) / 10` 为什么有效？`Math.round(82.45 * 10) / 10` 会得到什么？
- 同分并列时，怎么保证下一名次跳号是对的？
- 把数据渲染到页面时，为什么优先用 `textContent` 而不是 `innerHTML`？
- `setTimeout(() => ..., 1000)` 里的回调为什么不是立刻执行？

## 为下周做准备

本周你已经悄悄用到了一点浏览器能力：用 `document.querySelector` 找到容器、用 `createElement` + `textContent` 生成并插入元素。下周（第 4 周）会把它展开成完整的浏览器开发：

- 用 DOM 动态增删改页面元素；
- 用事件和事件委托响应用户操作；
- 用 `localStorage` 把数据保存在浏览器里；
- 第一次接触 `Promise`、`fetch`、`async/await` 这类「异步」代码。

如果本周的 `setTimeout` 选做让你好奇「为什么结果不是马上出来」，那就带着这个问题进入下周——这正是异步的入口。下周任务量比本周大，建议先把 DOM、事件、存储、模块做扎实，再进入异步。
