# 第 3 周学习指南：JavaScript 基础

> 本周用 JavaScript 完成“招新成员数据处理器”。重点是把复杂问题拆成小函数；数据格式、清洗规则和输出要求见 [task.md](./task.md)。

## 学完你能做什么

- 使用变量、条件、循环和函数表达业务逻辑；
- 使用数组和对象完成筛选、转换、统计和排序；
- 根据控制台报错定位常见语法与运行问题。

## 推荐学习顺序

1. 练习变量、数据类型、运算符和条件判断。
2. 用循环和函数解决几个独立的小问题。
3. 掌握 `map`、`filter`、`find`、`reduce` 和 `sort`。
4. 将数据清洗、统计和排名分别写成独立函数。
5. 完成 [task.md](./task.md)，最后再把摘要渲染到页面。

## 核心知识

- [ ] `const`、`let`、基本数据类型与类型转换；
- [ ] 条件语句、循环、函数参数和返回值；
- [ ] 数组方法与对象属性；
- [ ] 解构、展开运算符和模板字符串；
- [ ] 空值、非法值、重复数据的处理；
- [ ] 不修改原数组的数据处理方式；
- [ ] `JSON.stringify` 与 `JSON.parse`；
- [ ] Console 报错、日志和基础调试。
