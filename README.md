# 回声前端招新任务

一套面向前端初学者的分阶段实践任务，内容从开发环境与 Web 基础逐步过渡到 Vue 单页应用开发。

仓库包含第 00～08 周的学习指南、任务说明、练习素材，以及结业项目使用的 Express + SQLite 后端服务。

## 学习路线

| 周次 | 主题 | 主要内容 |
| --- | --- | --- |
| 00 | 前端与开发工具导学 | 开发环境、浏览器开发者工具、Git、npm |
| 01 | HTML 基础 | 语义化标签、表格、表单、锚点、相对路径 |
| 02 | CSS | 盒模型、Flexbox、Grid、定位、响应式 |
| 03 | JavaScript 基础 | 语法、函数、数组、对象、数据处理 |
| 04 | DOM 与异步 | DOM、事件、模块化、`localStorage`、`fetch` |
| 05 | Vue 基础 | Vite、单文件组件、响应式状态、计算属性 |
| 06 | Vue 组件化 | 组件拆分、Props、Emit、插槽、Composable |
| 07 | Vue 工程实践 | 接口请求、状态处理、表单校验、前后端联调 |
| 08 | Vue Router 结业项目 | 路由、导航守卫、懒加载、SPA 工程实践 |

第 05～08 周围绕同一个校园社团招新项目持续迭代，最终完成可运行的单页应用。

## 环境要求

- Node.js 22.5 或更高版本
- npm
- Git 2.23 或更高版本
- Chrome 或 Edge
- VS Code（建议安装 Live Server）

## 使用说明

每周目录主要包含以下文档：

- `学习指南.md`：本周需要掌握的知识与学习资料
- `task.md`：任务要求、交付内容与完成标准

建议按周次顺序学习。进入对应目录后，先阅读学习指南，再按照任务说明完成练习。具体文件结构和提交要求以各周的 `task.md` 为准。

## 后端服务

第 07、08 周需要使用 `后端服务/` 进行接口联调：

```bash
cd 后端服务
npm install
npm start
```

服务默认运行在 `http://localhost:3000`。接口说明见 [`后端服务/README.md`](./后端服务/README.md)。
