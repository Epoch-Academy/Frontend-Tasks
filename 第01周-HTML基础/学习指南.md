# 第 1 周学习指南：Web 入门与 HTML 基础

## 一、本周总学习目标

- 能说明浏览器打开网页后发生了什么；
- 能独立写出完整的 HTML5 文档骨架；
- 能根据内容含义选择合适的标签；
- 能正确引用本地图片、页面锚点和外部样式文件；
- 能使用开发者工具检查元素和资源错误。

## 二、本周学习任务

1. 了解浏览器、服务器、URL、HTTP 请求与响应的基本关系；
2. 手写 HTML5 文档骨架，掌握头部元信息和正文结构；
3. 完成文本、链接、图片、列表、表格和表单的基础练习；
4. 练习相对路径、站内锚点、语义化标签和基础可访问性；
5. 使用浏览器开发者工具检查页面元素、控制台报错和资源加载情况；
6. 按照 [task.md](./task.md) 完成“回声实验室信息页”：`image (2).png` 是页面**整体**效果图，`image (1).png` 是页面**底部（footer）**效果图；

## 三、知识点清单

- [ ] Web 页面、浏览器、服务器、URL 和 HTTP 的基本关系；
- [ ] `<!DOCTYPE html>`、`html`、`head`、`body`；
- [ ] `meta charset`、viewport、`title`、`link`；
- [ ] 标题、段落、强调、列表、链接和图片；
- [ ] 表格的表头、行与单元格；
- [ ] 表单、输入控件、按钮、`label`；
- [ ] 音频 `audio` 与视频 `video` 的基本用法；
- [ ] 块级元素与行内元素的基础认识；
- [ ] `class` 与 `id`；
- [ ] 相对路径、绝对路径与站内锚点；
- [ ] HTML 语义化和基础可访问性；
- [ ] 浏览器 Elements、Console、Network 面板；
