# 第 1 周学习指南：Web 入门与 HTML 基础

> 本周用 HTML 搭建“回声实验室信息页”。先关注内容结构是否清楚，不需要花时间美化页面；具体区块、素材和验收要求见 [task.md](./task.md)。

## 学完你能做什么

- 独立写出完整的 HTML5 文档；
- 根据内容含义选择合适的标签；
- 正确引用图片、音视频和页面锚点。

## 推荐学习顺序

1. 手写 `DOCTYPE`、`html`、`head`、`body`，理解页面基本骨架。
2. 练习标题、段落、列表、链接、图片、表格和表单。
3. 用 `header`、`nav`、`main`、`section`、`footer` 组织页面。
4. 练习相对路径、站内锚点，以及 `class` 和 `id`。
5. 完成 [task.md](./task.md)，再用开发者工具检查资源和标签结构。

## 核心知识

- [ ] HTML5 文档骨架与 `head` 中的元信息；
- [ ] 常用文本、列表、链接和媒体标签；
- [ ] 表格与表单的基本结构；
- [ ] 语义化标签；
- [ ] `label`、图片 `alt` 等基础可访问性要求；
- [ ] 相对路径、绝对路径与站内锚点；
- [ ] `class` 与 `id` 的区别。
