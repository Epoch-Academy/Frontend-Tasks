# 第 1 周任务：回声实验室信息页

## 任务目标

通过独立搭建一个**回声实验室信息页**，掌握 HTML5 文档结构、常用标签、语义化标签、表单、表格、站内锚点以及本地资源路径等知识点的基本用法。目标效果见本目录下的**两张**效果图：

- `image (2).png`：页面**整体**效果（头部与导航、实验室介绍、方向分组、开放时间、报名表单）；
- `image (1).png`：页面**底部（footer）**效果，包含一张带 `alt` 的本地图片、一个 `video` 视频播放器和一个「回到顶部」链接。

## 上周回顾

- 第 0 周你装好了工具链：Node.js / npm（≥ 22.5）、Git、VS Code + Live Server、浏览器开发者工具；本周只用到编辑器、浏览器和 Git 提交，Node.js 暂时用不上。
- 第 0 周练过的三条命令本周继续用：`git status` → `git add .` → `git commit -m "..."`（提交信息换成本周的内容）。

## 指引

重点关注以下内容：

- HTML5 文档声明及 `html`、`head`、`body` 的完整结构；
- 字符集、视口、页面标题等元信息；
- 标题、段落、列表、链接、图片、音频、视频、表格和表单标签等知识点；
- `header`、`nav`、`main`、`section`、`article`、`footer` 等语义化标签；
- `class`、`id`、图片替代文本以及相对路径；
- 站内锚点跳转（`id` + `href="#xxx"`）和外部样式文件的引入；
- 标签的正确嵌套、缩进和可读性。

## 本轮要求

> 本周目录下已经准备好了素材，直接引用即可：`assets/avatar.png`（图片）、`assets/music.mp3`（音频）、`assets/video.mp4`（视频）。两张效果图分别是 `image (2).png`（整体）与 `image (1).png`（底部）。

1. 新建一个能够直接在浏览器中打开的 `index.html`。
2. 参照 `image (2).png` 复刻整体页面、参照 `image (1).png` 复刻底部，页面必须包含以下区块（顺序可按自己的排版调整）：

   - `header`：实验室名称、副标题，以及一个 `nav` 导航（至少 3 个指向本页区块的锚点链接）；
   - `main` 内至少 3 个 `section`，每个 `section` 都要有自己的 `id` 和标题：
     - 实验室介绍（至少一段文字 + 一个 `audio` 音频播放器）；
     - 方向分组（一个列表 + 一个带 `thead`/`tbody` 的 `table` 表格）；
     - 报名表单（见第 3 条）；
   - `footer`：至少一张带 `alt` 的本地图片、一个 `video` 视频播放器，以及一个“回到顶部”锚点链接。

3. 报名表单至少包含姓名、性别（单选）、学号、邮箱、方向（下拉选择）和自我介绍（多行文本），
   **每个控件都必须有配套的 `label`，并用 `for` 与控件 `id` 关联**，控件都要写 `name`。
4. 使用 `link` 引入外部样式文件（例如 `assets/style.css`）。**本周不考样式**：CSS 是第 2 周的内容，你只要会用 `<link rel="stylesheet" href="...">` 把文件引进来、页面不报 404 即可；文件里写几行最基础的颜色/居中也没问题。如果你暂时不想建 CSS 文件，可以把这几行写在 `<style>` 标签里，但**第 2 周起必须改为外部样式文件**，且任何情况下都不使用行内 `style` 属性。
5. 页面内所有本地资源（`img`、`audio`、`video`、样式文件）使用相对路径引用，图片必须写 `alt`。
6. 主要内容使用语义化标签组织，不要全部使用 `div`。
7. 添加 `README.md`，说明页面包含哪些区块、资源放在哪个目录、相对路径是怎么写的，并用 Git 完成提交。

## 完成标准

- `index.html` 可以直接打开，中文显示正常；
- 页面头部结构完整，标签全部闭合，不存在错误嵌套；
- 第 2 条列出的内容区块全部存在；
- 图片、音频、视频可以正常加载，控制台没有资源加载错误；
- 导航锚点和“回到顶部”点击后能跳到对应位置；
- 表单每个控件点击文字标签都能聚焦到对应控件；
- 表格使用 `thead`、`tbody`、`th`、`td` 正确组织；
- HTML 缩进基本统一；
- 能现场说明 `head` 的作用、相对路径的含义，以及 `class` 与 `id` 的区别。
