# 第 2 周学习指南：CSS 样式与布局

> 本周给页面加入视觉样式，并完成个人卡片和响应式主页。具体效果图、页面内容和验收要求见 [task.md](./task.md)。

## 学完你能做什么

- 使用选择器为页面添加样式；
- 使用盒模型、Flexbox 和 Grid 完成常见布局；
- 让页面在不同屏幕宽度下保持可用。

## 推荐学习顺序

1. 学习 CSS 规则、选择器、层叠和继承。
2. 用盒模型调整尺寸、边框和间距。
3. 用字体、颜色、背景和阴影建立视觉层次。
4. 分别用 Flexbox 和 Grid 完成一组布局练习。
5. 加入媒体查询和交互状态，再完成 [task.md](./task.md)。

## 核心知识

- [ ] 常用选择器、伪类与伪元素；
- [ ] 层叠、继承和优先级；
- [ ] 盒模型与 `box-sizing`；
- [ ] 字体、颜色、背景、边框和间距；
- [ ] `display`、`position` 和 `overflow`；
- [ ] Flexbox 与 Grid 的适用场景；
- [ ] CSS 变量、媒体查询和响应式单位；
- [ ] 焦点态、对比度等基础可访问性样式。
