# 第 2 周学习指南：从基础样式到常用布局

## 一、本周总学习目标

- 能独立为 HTML 页面编写和组织 CSS 样式；
- 能解释层叠、继承、优先级和常见选择器的作用；
- 能使用盒模型、字体、颜色、间距和状态样式完成页面美化；
- 能用 Flexbox 和 Grid 完成常见布局；
- 能为页面补充基础响应式适配和可访问性样式；
- 能读懂并维护一份结构清晰、可复用的 CSS 代码。

## 二、本周学习任务

1. 认识 CSS 的作用、语法结构和三种引入方式；
2. 掌握常用选择器、伪类、伪元素和组合选择器；
3. 理解层叠、继承、优先级和 `box-sizing` 的影响；
4. 使用字体、颜色、背景、边框、圆角、阴影和透明度构建视觉层次；
5. 使用 `margin`、`padding`、`border` 和尺寸单位控制间距与版面；
6. 学会使用 `display`、`position`、`overflow`、`z-index` 等基础排版属性；
7. 掌握 Flexbox 和 Grid 的常见布局思路；
8. 了解响应式设计、媒体查询和移动端适配；
9. 养成样式复用、变量管理和命名规范的习惯；
10. 按照 [task.md](./task.md) 的要求，参照 `image1.png`（个人简介卡片）和 `image2.png`（响应式主页）完成两个页面的练习；

## 六、学习建议

1. 先把 HTML 结构写清楚，再考虑样式层次和视觉重点；
2. 每次只新增一类样式，观察浏览器中的实际效果；
3. 优先使用语义化 class 和可复用变量，减少重复定义；
4. 遇到样式冲突时，先查选择器和层叠关系，再考虑改写结构；
5. 为不同宽度的屏幕预留调整空间，不要依赖单一固定尺寸；
6. 保持样式文件分层清楚，基础样式、布局样式和组件样式分开思考。
