## 二、前端是什么

前端就是用户直接看到和操作的部分。你打开一个网页，看到的布局、按钮、输入框、动画、交互反馈，基本都属于前端要负责的内容。

前端最核心的三件事是：

1. `HTML` 负责结构和内容；
2. `CSS` 负责样式和布局；
3. `JavaScript` 负责交互和逻辑。

## 三、前端都要学什么

1. HTML：页面骨架、语义化标签、表单、图片、链接；
2. CSS：选择器、盒模型、布局、响应式、常见视觉效果；
3. JavaScript：变量、函数、数组、对象、事件、异步、模块；
4. 浏览器工具：Elements、Console、Network、Sources；
5. Git：版本管理、提交、回退、分支、协作；
6. 项目工具：Node.js、npm、Vite、包管理和依赖安装；
7. 框架：Vue / React 这类更高层的开发方式。

## 四、开发工具介绍

- **[VSCode](https://code.visualstudio.com/)**：主要编辑器，用来写代码、看目录、装插件；
- 当然你也可以选择下载 **[TRAE](https://www.trae.cn/)** 或者 [ZCode](https://zcode.z.ai/cn)等 AI IDE。
- 浏览器开发者工具：用来查元素、看报错、看请求、调样式；
- Live Server：本地打开静态页面，方便实时预览；
- Git：管理代码版本，记录每次修改；
- Node.js（node.js的下载建议使用nvm，nvm用来管理多个 Node.js 版本的工具，可以在电脑上快速切换不同 node 版本） 和 npm：安装前端工具和依赖，后面做项目会经常用到。

## 五、Git 基础

这里说的“Git”，其实就是把几个基础命令练熟：

- `git status`：看当前改了什么；
- `git add`：把改动放进暂存区；
- `git commit`：提交一个版本；
- `git log`：看提交历史；
- `git diff`：看改动内容；
- `git branch`：看分支；
- `git switch` 或 `git checkout`：切换分支；
- `git pull` / `git push`：拉取和推送代码。

你可以把 Git 理解成“保存进度条”。平时最重要的不是背命令，而是知道什么时候该提交、什么时候该看差异、什么时候该回退。
