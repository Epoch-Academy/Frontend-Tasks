# 第 0 周学习指南：认识前端与开发工具

> 本周先建立整体认识并搭好开发环境，不要求记住所有命令。目标是能打开项目、运行代码、查看报错并记录修改。

## 学完你能做什么

- 说清 HTML、CSS 和 JavaScript 各自负责什么；
- 使用编辑器、浏览器开发者工具和终端完成基本开发；
- 使用 Git 查看改动并提交一次代码。

## 推荐学习顺序

1. 认识前端：HTML 负责内容，CSS 负责样式，JavaScript 负责交互。
2. 安装 VS Code、Chrome 或 Edge、Git、Node.js 和 npm。
3. 打开浏览器开发者工具，找到 Elements、Console 和 Network 面板。
4. 在终端运行 `node -v`、`npm -v` 和 `git --version` 检查环境。
5. 练习一次 `git status` → `git add` → `git commit` 的基本流程。

## 接下来 8 周

| 阶段 | 学习内容 | 最终成果 |
| --- | --- | --- |
| 第 1～4 周 | HTML、CSS、JavaScript、DOM 与异步 | 能独立完成原生网页及交互 |
| 第 5～8 周 | Vue 基础、组件化、接口、路由 | 完成校园社团招新平台 |

第 5～8 周会持续迭代同一个 `campus-clubs` 项目，不需要每周重新创建。

## 核心知识

- [ ] HTML、CSS、JavaScript 的分工；
- [ ] 文件、文件夹、路径和扩展名；
- [ ] Elements、Console、Network 的用途；
- [ ] Node.js、npm 和本地开发服务器的作用；
- [ ] `git status`、`git add`、`git commit`、`git log`；
- [ ] 遇到报错时先阅读 Console，再搜索或询问 AI。

## 完成自检

- 能否用自己的话解释 HTML、CSS、JavaScript 的区别？
- 能否从 Console 中找到第一条报错及对应文件位置？
- 能否查看 Git 状态并完成一次提交？
