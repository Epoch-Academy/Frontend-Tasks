# 第 8 周学习指南：Vue Router 与结业项目

> 本周把 v0.3 单页改造成 v1.0 多视图 SPA，并加入登录与个人中心。继续复用已有 API、Composable 和组件，不要重新实现前几周的功能。

## 学完你能做什么

- 配置基础、动态、嵌套和 404 路由；
- 使用 params、query 和编程式导航组织页面跳转；
- 使用路由元信息和导航守卫限制页面访问。

## 推荐学习顺序

1. 安装 Vue Router，配置路由表、`RouterLink` 和 `RouterView`。
2. 把列表、详情和活动拆为页面，练习 params 与 query。
3. 增加个人中心及嵌套路由，练习编程式导航。
4. 接入登录状态，用 meta 和导航守卫保护页面。
5. 配置 404、重定向和懒加载，再按 [task.md](./task.md) 完整回归测试。

## 核心知识

- [ ] SPA、路由表、`RouterLink` 与 `RouterView`；
- [ ] `useRoute`、`useRouter`；
- [ ] params 与 query 的区别；
- [ ] `push`、`replace` 与浏览器历史；
- [ ] 嵌套路由与子级 `RouterView`；
- [ ] meta、导航守卫与登录后返回原地址；
- [ ] 404、重定向和路由懒加载；
- [ ] History 模式的服务器回退要求。
