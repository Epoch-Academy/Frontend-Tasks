## 二、本周总学习目标

- 理解 SPA 中 URL 与页面组件之间的关系；
- 能配置基础、动态和嵌套路由；
- 能正确使用 params、query 和编程式导航；
- 能使用 meta 与导航守卫实现简单访问限制；
- 能把前几周建立的 API 层、Composable、组件与收藏逻辑迁移进多视图结构；
- 能配置 404、重定向和路由懒加载；
- 能解释 History 模式部署回退要求。

## 三、本周学习任务

1. 安装并配置 Vue Router 4，把 v0.3 的单页拆成基础页面，使用 `RouterLink` 和 `RouterView`；
2. 使用动态 params 构建社团详情页，使用 query 保存搜索和分类条件；
3. 配置个人中心及其嵌套子路由；
4. 使用 `useRouter` 完成 push、replace 和登录后的编程式导航；
5. 使用 meta 与全局前置守卫实现简单登录限制和原地址返回。登录二选一（见 [task.md](./task.md) 的「指引」）：**已接第 7 周真实后端**（`后端服务/`，Express + SQLite）时，直接调用 `POST /api/auth/login` 并用第 7 周的 `useAuth` 管理登录态；**接口部分还记为「待补」**时，才用 `localStorage` 做前端模拟登录，并在 README 写明；
6. 配置 404、重定向、页面懒加载，并理解 History 模式部署回退；
7. 按照 [task.md](./task.md) 完成 v1.0，完整测试刷新、前进后退、退出登录、异常 id 和 404 场景；接口数据优先复用第 7 周形成的 API 层和 Composable。
