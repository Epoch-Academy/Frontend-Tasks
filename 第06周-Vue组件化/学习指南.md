# 第 6 周学习指南：Vue 组件化与组件通信 —— 社团招新平台 v0.2

## 〇、本周在主线项目中的位置

- 主线项目：`campus-clubs`（校园社团招新平台），已在上周完成 **v0.1 社团广场**（单页 + 本地数据）。
- 本周版本：**v0.2 组件化重构**。**不改数据模型、不加新业务功能**，只把 v0.1 的代码拆成合理组件并抽出 Composable。

## 一、上周回顾（v0.1）

你应该已经完成：

- 用 Vite 创建的 `campus-clubs` 项目可正常启动、构建；
- `src/data/clubs.js` 提供 ≥8 条社团数据（字段固定）；
- 单页实现搜索、分类筛选、排序、统计、收藏、本地持久化和空状态。

## 二、本周总学习目标

- 能按职责将页面拆分为合理组件；
- 能使用 Props 和 Emit 完成父子通信；
- 能使用插槽创建内容可替换的通用组件；
- 能在生命周期中正确注册与清理副作用；
- 能使用 Composable 复用有状态逻辑；
- 能在重构后保持原有功能不退化。

## 三、本周学习任务

1. 根据页面职责绘制组件树并确定状态归属；
2. 把 v0.1 的 `App.vue` 拆成 5 个以上组件，使用 Props 传值、Emit 传递操作意图；
3. 新增社团详情弹窗，用默认插槽和具名插槽制作通用 `BaseModal`；
4. 使用生命周期注册并清理 `Esc` 键等全局事件；
5. 将收藏逻辑封装为 `useFavorites` Composable；
6. 按照 [task.md](./task.md) 完成组件化重构；
7. 检查是否存在直接修改 Props、过度拆分或副作用未清理的问题，并在 README 中补充组件树与数据流说明。
