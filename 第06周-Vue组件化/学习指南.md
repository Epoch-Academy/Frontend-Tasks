# 第 6 周学习指南：Vue 组件化与组件通信

> 本周把 v0.1 重构为 v0.2。重点不是增加功能，而是让组件职责清楚、数据流容易追踪，并确保原有功能不退化。

## 学完你能做什么

- 根据职责拆分组件并安排状态归属；
- 使用 Props、Emit 和插槽完成组件通信与复用；
- 使用生命周期和 Composable 管理副作用与共享逻辑。

## 推荐学习顺序

1. 画出页面组件树，标出每份状态由谁拥有。
2. 拆分展示组件，用 Props 向下传递数据。
3. 用 Emit 向上传递操作意图，不在子组件中修改 Props。
4. 使用插槽实现通用弹窗，并在卸载时清理全局事件。
5. 把收藏逻辑抽成 Composable，再按 [task.md](./task.md) 检查全部功能。

## 核心知识

- [ ] 组件职责、拆分边界和状态归属；
- [ ] Props 与单向数据流；
- [ ] Emit 与自定义事件；
- [ ] 默认插槽和具名插槽；
- [ ] `onMounted`、`onUnmounted` 与副作用清理；
- [ ] Composable 的命名、输入和返回值；
- [ ] scoped 样式与组件复用。
