# 第 7 周学习指南：Vue 工程实践与前后端对接

> 本周把 v0.2 的本地数据替换为后端接口，并完成活动报名。重点掌握请求封装、页面状态和表单提交；接口字段与验收标准见 [task.md](./task.md)。

## 学完你能做什么

- 阅读接口文档并使用 `fetch`、`async/await` 请求数据；
- 封装 API 和异步 Composable，统一处理请求状态；
- 完成有校验、提交状态和错误反馈的报名表单。

## 推荐学习顺序

1. 启动后端，在浏览器中确认社团和活动接口可以访问。
2. 建立 `src/api` 请求层，统一基础地址、响应解析和错误处理。
3. 用 Composable 管理数据、加载、空数据、失败和重试状态。
4. 完成报名表单，处理前端校验、提交中状态和后端错误。
5. 配置环境变量与开发代理，最后用 Network 面板逐项自测。

## 核心知识

- [ ] 请求方法、query、path params、body 和状态码；
- [ ] `fetch`、`async/await` 与错误处理；
- [ ] API 模块与异步 Composable 的职责；
- [ ] 加载、成功、空数据、失败和重试状态；
- [ ] 表单校验、防重复提交和结果反馈；
- [ ] Vite 环境变量与开发代理；
- [ ] 前端校验不能替代后端校验。
