# 第 7 周学习指南：Vue 工程实践与前后端对接 —— 社团招新平台 v0.3

## 〇、本周在主线项目中的位置

- 主线项目：`campus-clubs`，已完成 **v0.1 社团广场**（本地数据）、**v0.2 组件化重构**。
- 本周版本：**v0.3 对接接口 + 报名**。把本地数据换成接口数据，建立 API 层，补齐请求状态，并新增「社团活动 + 报名」。
- 下周预告：v1.0 引入 Vue Router，把单页拆成多视图 SPA（结业项目）。

## 一、上周回顾（v0.2）

你应该已经完成：

- 组件化结构（`AppHeader`、`ClubFilter`、`ClubList`、`ClubCard`、`BaseModal`、`EmptyState` 等；其中 `BaseModal` 是第 6 周抽出的通用弹窗外壳，`ClubDetailModal` 是它的具体用法）；
- Props 向下、Emit 向上，子组件不直接修改 Props；
- 详情弹窗 + `Esc` 关闭，副作用已注册并清理；
- `useFavorites` Composable 收敛了收藏逻辑；
- v0.1 的搜索、筛选、排序、统计、收藏、持久化、空状态全部保留。

## 二、本周总学习目标

- 能在 Vue 项目中组织异步请求和请求状态；
- 能看懂并使用接口文档中的地址、方法、参数和返回值；
- 能完成请求封装、错误处理和开发代理配置；
- 能完成带校验、提交状态和反馈的表单；
- 能用 Composable 抽离异步数据逻辑；
- 能理解 provide/inject 的适用范围；
- 能使用环境变量和合理目录组织项目。

## 三、本周学习任务

1. 先阅读接口文档或模拟数据结构，明确列表、详情、提交三个核心接口分别返回什么；
2. 在主线项目中使用 `fetch` 和 `async/await` 获取社团与活动数据，区分 `query`、`params`、`body` 和请求头；
3. 建立加载、成功、空数据、失败和重试等完整请求状态；
4. 将请求封装为统一的 API 层（`src/api/*`），避免在组件里到处拼地址和重复写错误处理；
5. 将异步请求与筛选逻辑封装为 Composable（`useClubs`、`useActivities`），并复用 `useFavorites`；
6. 完成报名表单的校验、提交中状态、防重复提交和结果反馈；表单字段必须按 [task.md](./task.md) 的「报名接口契约」对齐（`activityId`、`name`、`studentId`、`contact`、`reason`，理由不少于 10 个字），并分别处理 400 / 404 / 409 三类失败；
7. 练习 `provide/inject`、Vite 环境变量、开发代理和项目目录组织；
8. 按照 [task.md](./task.md) 完成 v0.3，并测试请求成功、失败、空数据和重复提交等边界情况；
9. 尝试用浏览器 Network 面板或接口调试工具观察请求地址、状态码和返回数据。
