# 第 4 周学习指南：DOM、事件、存储与异步

> 本周把 JavaScript 逻辑接到页面上，完成原生 JavaScript 计算器。内容分为“页面交互”和“异步请求”两条线，先完成前者再学习后者。

## 学完你能做什么

- 使用 DOM API 更新页面，并通过事件响应用户操作；
- 使用 `localStorage` 保存数据，使用 ES Module 拆分代码；
- 使用 `fetch` 加载数据并展示加载、空数据和失败状态。

## 推荐学习顺序

1. 查询、创建、更新和删除页面元素。
2. 监听点击与键盘事件，再理解冒泡和事件委托。
3. 完成计算器核心逻辑，并把历史记录存入 `localStorage`。
4. 使用 ES Module 拆分计算、存储、渲染和入口代码。
5. 最后学习 `Promise`、`fetch`、`async/await`，补齐异步状态。

具体功能、异常场景和最低交付范围见 [task.md](./task.md)。

## 核心知识

- [ ] `querySelector`、`createElement`、`textContent` 和 `classList`；
- [ ] 事件对象、冒泡、默认行为和事件委托；
- [ ] 用户输入校验与安全展示；
- [ ] `localStorage` 与 JSON 序列化；
- [ ] ES Module 的导入与导出；
- [ ] `Promise`、`fetch`、`async/await` 和 `try/catch`；
- [ ] 加载、成功、空数据和失败状态。
