# 第 4 周任务：原生 JavaScript 简易计算器

## 本周定位

- **承接上周**：第 3 周你用纯 JavaScript 在控制台完成数据处理，并第一次用 `document.querySelector` + `createElement` 把摘要渲染到页面；本周正式进入浏览器，把它扩展成一个可点击、可保存、可联网的计算器。
- 本周内容明显比前几周多，因此按**两条线**推进：
  - **核心线（必须完成）**：DOM 操作 → 事件与事件委托 → `localStorage` → ES Module → 计算器主流程；
  - **异步线（进阶）**：Promise → `fetch` → `async/await` → 历史记录的四态处理。
- 时间紧张时，先保证**核心线完整跑通**，异步线可参照示例补齐（见下文「最低可交付标准」）。

## 上周回顾

## 本轮要求

1. 使用 HTML、CSS 和原生 JavaScript 完成计算器，不得使用 Vue、React 或 jQuery，**不得使用 `eval` 或 `new Function` 求值**。
2. 页面至少包含四个部分：表达式显示区（可以是一个 `input`）、按键面板、结果预览区、计算历史区。
3. 实现以下必做功能：
   - 输入数字 0-9 和小数点；
   - 加减乘除四则运算，且乘除的优先级高于加减；
   - 括号；
   - 清空（C）与退格（⌫）；
   - 等号（`=`）求值；
   - 计算成功后自动写入历史记录。
4. 输入校验：
   - 表达式为空、括号不匹配、运算符位置不对、数字格式错误时，必须给出明确提示，且不写入历史记录；
   - 除以零要单独提示，不能让页面崩溃，也不能把 `Infinity` 或 `NaN` 当成结果显示；
   - 求值失败时输入框要有可见的错误状态（例如变红），输入恢复合法后要取消该状态。
5. 键盘输入也要生效：数字、`+ - * /`、`(` `)`、`.`、`Backspace`、`Delete`、`Enter`、`Escape` 都能操作计算器。
6. 使用 `localStorage` 保存计算历史，刷新页面后历史仍然存在，最多保留最近 20 条。
7. 历史记录至少支持三种操作：点击一条记录把表达式回填到显示区、删除单条记录、清空全部记录（清空前要确认）。
8. 按键面板和历史列表都必须使用事件委托处理点击，不允许为每个按键或每条历史记录单独绑定事件。
9. 在 `data/history.json` 中准备至少 3 条示例历史，用 `fetch` 异步加载；只有在本地从未保存过历史时，才用它作为初始数据。
10. 历史区域必须分别处理加载中、加载成功、空数据和加载失败四种状态，失败时提供「重新加载」按钮，且页面不白屏。
11. JavaScript 至少拆分为两个模块，推荐拆成「计算逻辑」「数据存储」「界面渲染」「主入口」四个模块。
12. 添加 `README.md`，说明为什么需要通过本地服务器运行、数据保存位置、各模块职责以及表达式求值的实现思路。

## 提示

- 求值不要依赖 `eval`。可以先扫描字符串把表达式切成「数字、运算符、括号」三类记号，再按运算符优先级计算；
- 运算符优先级可以这样想：遇到新运算符时，只要栈顶运算符的优先级不低于它，就先把栈顶弹出来计算，最后处理括号内的部分；
- 一元负号（如 `-5`、`3*-2`、`-(1+2)`）可以在切分记号时判断：当 `-` 出现在**表达式开头**、**左括号之后**、**另一个运算符之后**，它就是负号而不是减法；本周至少要把 `-5` 和 `3*-2` 算对，`-(1+2)` 属于加分项；
- 表达式里的乘除可以用 `×` `÷` 展示，计算前统一替换成 `*` `/` 再处理，避免两套符号各写一遍逻辑。

## 完成标准

**核心线（必达）**

- 运算结果正确：`2+3*4` 得到 14，`(1+2)*3` 得到 9，`-5+1` 得到 -4，`3*-2` 得到 -6；
- 表达式为空、括号不匹配、除以零、非法字符都有明确提示，控制台没有未捕获错误；
- 鼠标点击与键盘输入两种方式都能正常使用；
- 刷新页面后历史记录能够恢复，最多 20 条；
- 动态新增的按键与历史记录都不需要逐个重新绑定相同事件；
- 用户输入通过 `textContent` 等安全方式展示，不拼接为可执行 HTML；
- 全项目不出现 `eval` 与 `new Function`；
- 能现场说明事件冒泡、事件委托和 JSON 序列化的基本工作方式。

**异步线（在核心线达标之后完成；验收时按同一份清单核对）**

- 历史区在请求过程中有加载提示，请求失败时页面不白屏且可以重试；
- 能现场说明 `async/await` 的基本工作方式。
